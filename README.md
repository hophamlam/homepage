# Homepage - Astro + shadcn/ui

Personal homepage built with Astro and shadcn/ui, featuring Profile, Contact, and Side Projects sections.

## Features

- ⚡ Built with [Astro](https://astro.build)
- 🎨 Styled with [Tailwind CSS](https://tailwindcss.com)
- 🧩 UI components from [shadcn/ui](https://ui.shadcn.com)
- 🌓 Dark mode support
- 📱 Fully responsive
- 🚀 Optimized for performance

## Tech Stack

- Astro 4.x
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui (orange theme)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
