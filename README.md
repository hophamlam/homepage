# Homepage

Personal homepage built with Astro and shadcn/ui.

## Features

- ⚡ Astro + React + TypeScript
- 🎨 Tailwind CSS v4 with OKLCH color palette
- 🧩 shadcn/ui components
- 🌓 Dark/Light mode toggle
- 🌐 Multi-language (EN/VI)
- 📱 Fully responsive

## Getting Started

```bash
npm install
npm run dev
```
